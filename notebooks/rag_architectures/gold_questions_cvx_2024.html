How to read it. PDF page is the page in the PDF file; printed page is the number in the page footer, where there is one. Figure is the value as printed; × 1,000,000 means the report prints it in millions. For tables, the passage is the printed row read left to right, and its columns are years in the order the table shows them. For charts, the passage is the printed label; tying it to a series needs the chart itself. For unanswerable questions, the passage column gives the reason, and "checked absent" lists the terms confirmed missing from the whole PDF by verify_eval_set.py.

1. Upload the PDF first

Put EDGAR_ARS_CVX_2024.pdf in Google Drive at My Drive / rag_arch / EDGAR_ARS_CVX_2024.pdf before running. The folder name is rag_arch, all lowercase, and every notebook uses it. If the PDF isn't there, the notebook shows an upload button partway through the run and saves the file into the folder; uploading first lets you run all cells unattended. The notebook checks the file's fingerprint: with a different PDF it still answers questions but skips the scoring.

2. Run each notebook

  1. File → Upload notebook, and pick one of 04–08 from notebooks/rag_architectures/.
  2. Runtime → Change runtime type → T4 GPU.
  3. In the "Run options" cell keep USE_DRIVE = True and DRIVE_FOLDER = "rag_arch", and set QUICK_TEST = False for real scores; a quick run overwrites the results file.
  4. Notebook 08 only: set SEC_CONTACT to your name and email. The SEC requires it, and it is sent only to sec.gov. Left blank, the notebook stops and asks for it.
  5. Runtime → Run all, and approve the Google Drive prompt.

Run 04 before 06: 06 reuses the page transcriptions 04 saves in rag_arch, which saves it about 20 minutes. For 08 to compare against 01–03, first copy their CSVs from notebooks/rag_architectures/results/ into rag_arch; 08 compares against every results file in that folder. A "set a HF_TOKEN" warning only means slower downloads.

3. Collect the results

Fixes made while checking

  • Notebooks 04, 06 and 07 passed min_pixels/max_pixels to the vision model's processor, and transformers 5.23 removes them. Each page image is now shrunk to the same pixel budget before it is sent (82 × 62 patches, against 80 × 62 before), so it doesn't depend on the transformers version.
  • The install line had pydantic>=2 unquoted. In Colab's ! shell the > wrote pip's output to a stray file called =2. It is quoted now.
